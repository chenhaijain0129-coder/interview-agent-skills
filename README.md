# Interview Agent Skills — 已拆分

> 本合集已于 2026-09-19 拆分为两个独立维护的公开仓库。为了避免旧链接失效，本仓库暂时保留作为导航页；请从下方独立仓库安装和获取更新。

## 包含的 Skills

### [Interview Prep Skill](https://github.com/chenhaijain0129-coder/interview-prep-skill)

根据目标公司、岗位 JD、面试轮次和用户主动提供的经历，生成结构化面试准备材料。独立仓库提供完整部署指南、提示词示例、英文说明和版本记录。

### [Group Interview Skill](https://github.com/chenhaijain0129-coder/group-interview-skill)

适用于商业案例、产品运营、资源分配、公共议题、危机处理和创意策划等无领导小组讨论。独立仓库提供部署、题型说明和临场提示词示例。

## 安装与更新

请进入对应独立仓库，按照 README 或 `docs/deployment.md` 安装。独立仓库中的版本将继续更新；本合集不再作为安装源。

## 隐私与事实边界

- 仓库不包含真实简历、联系方式、内部项目资料或本机路径。
- 用户经历只在当前对话中由用户主动提供。
- Skill 不编造项目、数据、职责或公司内部信息。
- 涉及最新公司、产品或市场信息时，应查证公开来源并区分事实与推断。

## 参与贡献

欢迎提交 Issue 或 Pull Request。修改 Skill 时，请保持触发描述清晰、避免引入个人资料，并确保引用文件能从对应的 `SKILL.md` 找到。
